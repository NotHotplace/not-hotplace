# NotHotplace 4주 운영·홍보 계획

이번 개선으로 장소는 401곳에서 30개국 1,006곳으로 늘어난다. 추가한 605곳은 세계 도시의 장소 105곳과 뉴욕시 공원 자료 500곳이다. 추가분 중 4곳은 운영기관 방문 안내까지 확인했고, 601곳은 기본 소개 단계다. 기본 장소는 검색용 사이트맵에서 제외하고 noindex로 표시한다. 나라 검색·대륙 필터·세계 가이드 7개로 찾아보기 쉽게 연결한다.

## 방문과 후기가 적은 이유: 검증할 가설

낮은 브랜드 인지도, 검색할 만한 구체적인 방문 정보 부족, 계획 단계에 있는 독자, 로그인 부담, 긴 후기 작성 방식, 모호한 참여 요청, 부족한 실제 사진을 살펴본다. 검색 순위·고유 방문자 자료를 확인하지 못했으므로 원인으로 단정하지 않는다. 뉴욕 자료가 많아 다음에는 유럽·중앙아시아·아시아의 대표 장소부터 자세히 채운다.

## 1주차 — 검색하고 들어올 이유 만들기

새 지역마다 대표 장소 3곳의 운영 시간·요금·입구·주차·좌석을 공식 안내에서 확인한다. 항목마다 출처와 확인 날짜를 남기고 사용 권한이 있는 사진을 추가한다. 국가·가이드·장소를 서로 연결한다. 인스타는 소개한 가이드로 바로 연결한다. Search Console 계정에 접근할 수 있을 때 사이트맵 제출·색인 상태를 확인한다. 확인하지 않은 검색 노출을 성공했다고 표시하지 않는다.

## 2주차 — 저장에서 실제 방문 후기까지

게시물마다 행동 하나를 요청한다. 방문 전에는 ‘가볼 곳을 기기에 저장’, 다녀온 뒤에는 ‘조용함·보통·시끄러움 중 하나 선택’을 안내한다. 좌석·가격·사진 제보는 로그인 없이 짧게 받는다. 사진 링크는 공개 사용 동의를 받고, 관리자 검토 뒤 반영한다. 외부 후기 메모는 우리 사이트의 실제 이용자 후기 수에 합산하지 않는다.

## 3주차 — 사진과 픽토그램으로 설명하기

실제 장소 사진, 가격·주차·좌석 그림, 방문 조건 한 가지를 함께 보여준다. 나라별 가이드에서 균형 있게 소재를 고른다. 주차 불가와 정보 미확인을 구분하고, 다인석 그림을 정확한 수용 인원처럼 쓰지 않는다. 기존 Metricool 예약을 UUID로 찾아 수정하며 시각과 미디어를 유지한다. 중복 예약은 만들지 않는다. 국내 사진을 해외 현장 사진처럼 설명하지 않는다.

## 4주차 — 반응을 보고 다음 확장 정하기

동일한 길이의 7일 기간을 비교한다. 가이드 조회·장소 조회·지도 열기·저장·후기 시작·로그인 시도·간단 소음 응답을 국가·홍보 주제별로 살펴본다. 행동 횟수 집계이므로 고유 이용자나 전환율로 부르지 않는다. 조회만 늘면 사진·방문 안내를 보강하고, 저장은 늘지만 후기가 적으면 방문 후 ‘내 쉼 기록’에서 돌아오는 안내를 분명하게 한다. 관심을 받는 나라의 장소부터 상세 정보를 채운다.

## 비용과 운영 범위

기존 호스팅·Metricool을 사용한다. 유료 광고, 추가 결제 계약, 유료 지도 API, 자동 재게시, 현장 QR은 이번 범위에 넣지 않는다. 장소 증가에 따른 방문자·검색 순위 상승은 실제 반응으로 확인한다.

## 자료 관리

배포 전 node scripts/audit-catalog.cjs로 중복 ID·국가·출처·좌표·사진 권한·정보 단계를 확인한다. 변경 가능한 시간·가격·휴무는 공식 안내를 다시 확인한다. 지도 기준점과 실제 입구를 구분한다. 구글·네이버·카카오·Tripadvisor 원문을 대량 복사하지 않고, 실제 열람한 화면 범위를 밝힌 짧은 메모를 쓴다.
