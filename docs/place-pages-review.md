## 목적과 변경 내용

기존 장소는 지도 목록과 대화창에서만 볼 수 있어, 개별 장소를 검색·공유할 때 필요한 독립 소개 페이지가 없었습니다. 현재 등록된 한국 324곳·미국 12곳을 각각 한글과 영어 주소로 열 수 있도록 준비했습니다. 장소 수가 늘어난 것은 아닙니다.

- `/places/{장소 ID}/ko`와 `/places/{장소 ID}/en`에서 사진, 소개, 주소, 등록된 방문 정보, 출처와 자료 확인일을 제공합니다.
- 기존 사진의 저작자·이용 조건·출처를 표시하고, 사진이 없는 장소는 사진 미등록 상태로 보여줍니다. 등록된 공식 사진 모음 링크도 노출합니다.
- 개별 제목·설명·공유 이미지, 언어별 검색 주소와 구조화된 장소 정보를 생성합니다. 존재하지 않는 평점이나 혼잡도는 생성하지 않습니다.
- 사이트맵에 기존 소개 페이지 6개와 장소별 언어 주소 672개를 포함합니다. 검색 노출이나 순위 상승을 보장하는 것은 아닙니다.
- 지도 목록에 상세 페이지 링크를 추가하고, 기존 장소 공유를 독립 페이지로 연결합니다.
- 승인된 사용자 제안은 기존 실시간 탐색 링크를 유지해 연결이 끊기지 않도록 했습니다.
- 후기 작성 중 로그인할 때 선택한 장소가 로그인 이후에도 유지되도록 복귀 주소를 보완했습니다.

예시 주소는 배포 후 다음 형태가 됩니다.

- `/places/us-stumptown-division/en`
- `/places/us-stumptown-division/ko`
- `/places/tour-4108662/ko`

## 반영 범위

2026-09-27 운영 반영 승인을 받아 별도 브랜치와 PR을 통해 반영합니다. GitHub 검사 통과 후 main에 병합하고 기존 Cloudflare Workers Builds 연결로 배포합니다. 실제 배포 상태는 해당 커밋의 Workers Builds 검사와 운영 URL에서 확인합니다.
